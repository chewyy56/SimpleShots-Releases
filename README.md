# SimpleShots Releases

This repository contains public releases for SimpleShots, a modern shot list and storyboard tool for film and TV production.

## Download

Download the latest version from the [Releases](https://github.com/chewyy56/SimpleShots-Releases/releases) page.

## About

SimpleShots features:
- Shot planning with size, angle, movement, lens and notes
- Storyboard and Line Script views
- Cast and character notes alongside every shot
- Scene sync from a SimpleStrips schedule
